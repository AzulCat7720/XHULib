# 西瓜小图 XHULib · Android 客户端

西华大学图书馆书目检索系统（江苏汇文 OPAC v5.6.1）的第三方 Android 客户端，
面向普通学生，界面遵循 **Material Design 3**。

> **非官方应用 —— 由学生自制，与西华大学图书馆及江苏汇文软件公司均无关联。**
> 数据全部来自学校图书馆公开的检索系统，本应用不架设任何服务器，
> 不收集、不上传任何个人信息。首次启动会显示免责声明，同意后方可使用。

## 功能

### 首页
- 顶部搜索栏（点击进入检索页），**右侧同行一个小铃铛按钮**，点击进入独立的消息通知页
- **热门推荐**横向卡片（来自「热门借阅」排行，可点进详情）；
  右上角「更多」进入完整排行页，含 热门借阅 / 热门评分 / 热门收藏 / 热门图书 四个标签
- 提醒徽标：即将过期 / 已超期 / 预约到书 / 委托到书（为 0 不显示）
- **当前借阅大卡片**：书名、应还日期、剩余天数（≤5 天标红）

### 发现页（顶部切换）
- **分类浏览**：中图法 22 个大类。分类用**下拉展开的网格面板**选择
  （超大类别如文学 / 工业技术 / 经济，图书馆的分类浏览页会返回 HTTP 500 ——
  这是馆方系统自身的限制；App 会自动改用**按分类号检索**兜底，
  并校验结果的分类号确实匹配，宁可不显示也不给错书）
  （原来是横向筛选条，22 个大类挤在一行里要滑很久）；
  选中大类后下面出现**子类筛选行**（A → A1/A2/A3/…），可进一步收窄
- **新书通报**：按分类浏览近 30 天新书，同样支持下拉网格 + 子类筛选
- **期刊导航**：刊名拼音 / 西文字母 / 学科导航 / 年度订购 四个子标签，
  期刊均可点进详情
- **学科参考**：12 个学科门类、386 个学科

### 我的页
- 顶部：账号 + **账号切换** + **设置**
- **证件信息大卡片**（姓名、证件号、读者类型、系别、借阅额度）
- 左上角是按**北京时间**变化的问候语（卡片里已有证件号，不再重复显示）
- 单行栏：我的书架、我的书评、借阅历史、**读者荐购**、检索历史、我的课程、
  预约信息、委托信息、书刊遗失、账目清单、我的积分
- 页面末尾单列一组「**以下需到图书馆网站办理**」：读者挂失、违章缴款
- 「课程完成度」并入「我的课程」页顶部（添加课程是写操作，只做引导）

  > 站点「我的图书馆」的 18 个栏目到此全部可达（当前借阅在首页大卡片里）。

其中：
- **读者荐购**（只读）：对应图书馆的 `asord/asord_hist.php`——那是**荐购专区**，
  内含三个子标签，App 原样还原：
  - **荐购历史**：你荐购过的书、日期与处理状态
  - **读者荐购**：提交表单（写操作，需登录），只做提示并引导到图书馆网站
  - **新书目录推荐**：征订目录，可看每本书属于哪个中图法分类、已有多少人推荐过
- **违章缴款**与**读者挂失**只做提示页，引导到
  `http://202.115.151.118:8080/` 办理，**App 不发起任何写操作**
  （挂失需密码且系统明确警告"挂失后自己不能解除，需要工作人员处理"，误触代价高）

### 离线缓存

每页抓成功都会缓存到 App 私有目录；**没连校园网时自动退回缓存**，
并在底部显示「离线数据 · 更新于 …」，避免把旧数据当成实时数据。

- 冷启动连不上服务器时，只要有缓存就直接进主页，不再只弹错误页
- 退出登录会连同缓存一起清掉（缓存里有借阅记录、证件信息等个人数据）
- 设置页可查看缓存占用并手动清除

### 分页

借阅历史、我的积分、检索历史、荐购历史、征订目录在服务端都是**分页**的
（`?page=N`），列表底部有「加载更多」，不会只显示第一页。

### 检索

搜索框会记住**最近 20 条检索词**（存在本地，关掉 App 也不丢），可一键清空。
图书馆系统自己也有一份「检索历史」，那份要登录才看得到，二者互不影响。

### 多语言

界面支持**简体中文 / 繁體中文 / English** 三种语言。应用名也随语言变化：

| 语言 | 应用名 |
|---|---|
| 简体中文 | 西瓜小图 |
| 繁體中文 | 西瓜小圖 |
| English | XHULib |


- 首次启动**自动检测设备语言**；非简中、繁中、英文时回落简体中文
- 设置里可手动切换，切换后**立即生效**（不需要重启 App）
- 面向用户的文案全部走 `strings.xml`，包括数据层产生的错误提示
  （以字符串资源 ID 传递，由界面按当前语言解析）
- 解析器里用于匹配服务器 HTML 的列名（`题名`、`责任者`…）**不参与翻译** ——
  它们匹配的是图书馆系统返回的中文，翻译了反而会解析失败

### 设置
- 服务器地址、关于（含**版本号**与 **GitHub 仓库**入口）
- **界面语言**：跟随系统 / 简体中文 / 繁體中文 / English
- **夜间模式开关**：默认跟随系统，拨动开关即固定为深色/浅色，也可一键恢复「跟随系统」
- **自定义全局背景图片**：从相册选一张图作为全局背景（图片会复制进 App 私有目录，
  因此重启后仍然有效）。设置背景后纯色底色不透明度归零、只留一层轻蒙版保证文字可读；
  清除后恢复原来的纯色背景
- **过渡动画开关**：页面切换转场默认 180ms（Navigation Compose 默认是 700ms，
  手机上明显拖沓），可在设置里一键关闭动画
- **离线缓存**：查看占用、一键清除
- 退出登录 / 退出并删除本机账号（均需二次确认）

### 其他
- 消息通知页：预约到书 / 委托到书 / 超期欠款 / 超期催还 / 信息公告
- 书目检索：6 种检索项 × 3 种匹配方式，结果 → 详情（完整书目字段 + 馆藏表）
- **一次登录，重启免登录**（详见下文）

## 登录机制（本项目的技术核心）

汇文 OPAC 的登录有 4 个要素，缺一不可：

| 要素 | 来源 |
|---|---|
| 会话 Cookie | `reader/login.php` 返回的 `PHPSESSID` |
| `csrf_token` | 登录页隐藏字段 |
| **`sca` 密码混淆表** | **`reader/ajax_ep.php` 异步注入的 62 字符表，每次会话都不同** |
| 4 位图形验证码 | `reader/captcha.php`，大写、区分大小写、**一次性** |

密码不是明文提交：每个字符按 `sca` 表后移 3 位取码点，再膨胀成
`随机字符 + 十六进制码点 + 随机字符` 共 4 个字符（见 `PasswordCodec`）。

> ⚠️ `login.php` 的 HTML 里**没有** `sca` 字段，它由
> `$("#epa").load("ajax_ep.php")` 注入。漏掉这一步，服务器只会回
> 「用户名或密码错误」，**不会提示是编码问题**——这是接入时最容易踩的坑。

### 免登录策略

服务端会话存活时间很短（实测几分钟），所以采用：

1. 启动时用本地保存的 Cookie 试探一次 `redr_info.php`
2. 仍有效 → 直接进主页，用户无感知
3. 已失效 → 回到登录页，**账号密码自动填好**，用户只需看图输 4 个字符
4. 使用过程中失效 → 数据层广播 `SessionEvents.expired`，根组件自动切回登录页

本地只保存：账号、登录方式、密码、会话 Cookie。
**全部经 Android Keystore 的 AES-256/GCM 加密**，密钥不出安全硬件，不参与系统备份。

## 构建

### 方式一：Android Studio（推荐）

克隆后直接用 Android Studio 打开即可 —— Gradle Wrapper 已随仓库提供。

> Wrapper 默认走**华为云镜像**下载 Gradle（官方源在国内会跳到 GitHub，通常拉不动）。
> 境外网络可以改成官方源，见 `gradle/wrapper/gradle-wrapper.properties` 里的注释。

### 方式二：命令行 + 项目内自包含工具链

仓库自带一套安装脚本，把 JDK / Android SDK / Gradle 全装在项目内的 `.toolchain/`
（免 root，删掉即卸载，已 gitignore）：

```bash
bash tools/setup-toolchain.sh     # JDK 21 + Android SDK 35 + Gradle 8.11.1（约 2~3GB）
bash tools/build.sh assembleDebug # 产出 app/build/outputs/apk/debug/app-debug.apk
bash tools/build.sh testDebugUnitTest
bash tools/build.sh lintDebug
```

`tools/build.sh` 会设置 `JAVA_HOME` / `ANDROID_HOME` / `ANDROID_USER_HOME` / `GRADLE_USER_HOME`
全部指向项目内，不碰 `~/.android` 与 `~/.gradle`。

用 Android Studio 打开也可以，但需要自行把 SDK 指到 `.toolchain/android-sdk`。

## 测试

```bash
bash tools/build.sh testDebugUnitTest
```

- `PasswordCodecTest` —— 密码混淆算法逐字符校验（含表尾取模回绕、表外字符）

  离校网络下会自动跳过而不是失败。

## 架构

```
data/
  Opac.kt              端点常量
  OpacRepository.kt    取页面 → 解析 → 领域模型（挂起函数）
  SessionManager.kt    会话状态机（免登录 / 切换账号 / 退出）
  SessionEvents.kt     会话失效广播
  net/                 OpacClient（OkHttp 会话）、PasswordCodec、CryptoBox、Cookie 持久化
  parse/               Html（按表头定位的通用工具）、ReaderParsers、CatalogParsers
  store/               SecurePrefs（Keystore 加密）、AccountStore（多账号）
ui/
  XhuApp.kt            根组件：启动试探 / 登录页 / 三页导航 + NavHost
  theme/               Material 3 主题（墨绿 seed，支持深色模式）
  home/ discover/ mine/ login/ search/ notice/ reader/ account/ settings/
  common/              UiState、StateContent、BigRow、SectionRow 等复用组件
  nav/                 路由与栏目枚举
```

**解析策略**：全部**按表头文字定位**，不硬编码 CSS 路径——汇文各栏目版式差异不小，
但「题名 / 责任者 / 借阅日期」这类列名是稳定的。

## 已知限制

- **首次使用必须在校园网 / 学校 VPN 内**；之后没网也能看缓存下来的内容（会标注「离线数据」）
- 服务端会**主动打码**敏感字段（证件号、身份证号、电话、Email 等），
  App 只能显示系统给出的那份
- 服务端会话很短，长时间不用后需要重新输一次验证码。
  这种情况下登录页会明确提示「登录状态已过期」，不会让人莫名其妙地被登出
- 没有服务端推送，消息只能在打开 App 时拉取
- **第一版严格只读**：不含续借、取消预约/委托、荐购提交、挂失等任何写操作
- 「当前借阅」页在有在借图书时才会出现表格，该账号当时无借阅记录，
  因此其列名是按汇文标准列名实现的，未用真实数据验证
