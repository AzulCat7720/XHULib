## 1. 登录流程（关键）

登录需要 **4 个要素**，缺一不可：

```
① 会话 Cookie  (PHPSESSID)
② csrf_token   (登录页隐藏字段)
③ sca          (62 字符密码混淆表，每会话不同，异步注入)
④ captcha      (4 位图形验证码，大写、区分大小写、一次性)
```

### 1.1 取参顺序

| 步骤 | 请求 | 取得 |
|---|---|---|
| 1 | `GET /reader/login.php` | `PHPSESSID`、`csrf_token`（`<input name="csrf_token">`）|
| 2 | `GET /reader/ajax_ep.php` | JS 片段，动态创建隐藏字段 `sca`，值为 62 字符随机表 |
| 3 | `GET /reader/captcha.php` | 160×40 PNG，4 字符验证码 |

> ⚠️ 步骤 2 极易被忽略：`login.php` 的 HTML 里**根本没有 `sca` 字段**，它由
> `$("#epa").load("ajax_ep.php")` 异步注入。不发 `sca` 或发错，服务器只会回
> `对不起，用户名或密码错误`，**不会提示是编码问题**。

### 1.2 密码混淆算法

`login.php` 内联 `encode()` 的等价实现：

```python
def encode_password(pw: str, sca: str) -> str:
    """sca 为 62 字符表；每个明文字符膨胀为 4 个字符。"""
    out = []
    for ch in pw:
        idx = sca.find(ch)
        if idx == -1:                                  # 不在表内 -> 直接用码点
            code = format(ord(ch), "x")
        else:                                          # 表内 -> 后移 3 位
            code = format(ord(sca[(idx + 3) % 62]), "x")
        out.append(sca[random.randrange(62)] + code + sca[random.randrange(62)])
    return "".join(out)   # 1 明文字符 -> 随机字符 + 2 位十六进制 + 随机字符
```

### 1.3 提交

```
POST /reader/redr_verify.php
Content-Type: application/x-www-form-urlencoded

number=<学号>&passwd=<混淆后密码>&captcha=<4位>&select=cert_no&returnUrl=&csrf_token=<token>
```

`select` 取值：`cert_no`（证件号）| `bar_no`（条码号）| `email`（邮箱）

### 1.4 结果判定

| 服务器返回 | 含义 |
|---|---|
| `<font id="fontMsg" color="red">验证码错误(wrong check code)</font>` | 验证码错（**且该验证码已作废**）|
| `<font id="fontMsg" color="red">对不起，用户名或密码错误，请查实！</font>` | 账号/密码/密码混淆 三者之一有问题 |
| 无 `fontMsg` 报错 | **登录成功**，之后 `GET /reader/redr_info.php` 返回读者首页 |

### 1.5 会话特性

- 登录态绑在 `PHPSESSID` 上，**存活时间很短**（实测数分钟内失效）
- 会话失效后访问 `reader/*.php` 会返回登录页（可用 `name="frm_login"` 是否出现来判定）
- **结论**：一次成功登录后必须**立刻把需要的页面全部拉完**，不能分次慢慢取

### 2.1 我的首页（`redr_info.php`）

- 顶部四个提醒数字：**5 天内即将过期图书 / 已超期图书 / 预约到书 / 委托到书**
- 额度：最多可借 / 最多可预约 / 最多可委托
- 积分：总积分 / 可用积分
- 待办计数：超期图书、委托到书、预约到书、荐购图书（已订购）
- 借阅分析：**借阅分类分布 / 借阅时间分布 / 借阅趋势 / 阅读达人**（含百分位排名）
- 课程完成度

### 2.2 证件信息（`redr_info_rule.php`）

顶部提示条：`五天内即将过期图书[N]，已超期图书[N]，预约到书[N]，委托到书[N]`

字段：姓名、证件号、条码号、失效日期、办证日期、生效日期、最大可借图书、最大可预约图书、
最大可委托图书、读者类型、借阅等级、累计借书（册次）、违章次数、欠款金额、系别、Email、
身份证号、工作单位、职业/职称、职位、性别、住址、邮编、电话、手机、出生日期、文化程度、
押金、手续费

附表「适用的借阅规则」：规则名称、适用馆藏地、图书流通类型、最大借阅册数、借期、预约、续借
